# عميل PWF Auth لسطح المكتب بلغة C#

تستخدم هذه النسخة **PWFAuth 1.7.0**. يستعيد ملف NuGet.Config المرفق حزمة SDK الرسمية الموثّقة من المجلد vendor/، والحزمة نفسها منشورة على nuget.org. الإصدار PWFAuth 1.4.0 وما قبله لا يستطيع التواصل مع الخادم الحالي (فالخادم يوقّع ردوده بمفتاح جديد)، لذا حدّث النسخ القديمة

مثال بواجهة Windows Forms إنجليزية لحزمة [`PWFAuth` على NuGet](https://www.nuget.org/packages/PWFAuth) الرسمية (الإصدار 1.7.0) على .NET Framework 4.8.1. ما يفعله التطبيق:

- يسجّل الدخول بمفتاح الترخيص؛
- يُبقي الجلسة نشطة عبر التحقق الدوري (heartbeat) في الخلفية؛
- يسجّل الخروج عندما ينهي الخادم الجلسة؛
- يعرض رد تسجيل الدخول كاملاً في لوحة التحكم؛
- يحفظ قيمة على الخادم مرتبطة بالمفتاح (متغير مستخدم)

![لوحة التحكم بعد تسجيل الدخول](docs/dashboard.png)

## ما يعرضه المثال

- **تسجيل الدخول بمفتاح الترخيص.** تربط `LoginAsync` المفتاح بهذا الحاسوب، ثم تعرض لوحة التحكم:
  - حالة المفتاح ونوعه وتاريخ انتهائه والوقت المتبقي؛
  - مَن باع المفتاح؛
  - كل حقل في الرد
- **الإيقاف عن بُعد.** يبدأ `StartHeartbeat` بعد تسجيل الدخول. عندما تحظر المفتاح أو توقفه مؤقتاً أو تعيد ضبطه من لوحة التحكم، أو عندما تنتهي صلاحيته، تطلق الحزمة الحدث `SessionEnded` ويعود التطبيق إلى صفحة تسجيل الدخول مع ذكر السبب. يصل الحدث على مؤشر ترابط الواجهة، فلا حاجة إلى `Invoke`
- **نقل الترخيص إلى حاسوب جديد.** عندما يكون المفتاح مربوطاً بحاسوب آخر، تعرض صفحة تسجيل الدخول الخيار **Move this license to this PC**. يستدعي هذا الخيار `ResetHardwareIdAsync` ثم يسجّل الدخول من جديد. تسري مدة الانتظار التي يحددها المطوّر بين عمليتي نقل (12 ساعة افتراضياً)

  ![الخيار Move this license to this PC](docs/move-license.png)

- **متغيرات المستخدم.** بعد تسجيل الدخول يقرأ التطبيق `sample_opens` ويزيده واحداً ثم يحفظه عبر `GetVariableAsync` / `SetVariableAsync`، ويعرض "Opened N times with this key" تحت العنوان، ويسرد كل متغيرات المفتاح (`GetVariablesAsync`) في جدول التفاصيل. افتح المفتاح في لوحة التحكم (**Licences → المفتاح → Variables**): ستجد العدد هناك، وأي قيمة تغيّرها هناك هي ما سيقرؤه التطبيق في المرة القادمة. تنتقل المتغيرات مع المفتاح إلى الحاسوب الجديد
- **رسائل خطأ واضحة.** يعرض التطبيق رسالة بسيطة في الحالات التالية:
  - عدم وجود اتصال بالإنترنت؛
  - رفض الخادم سر التطبيق (HTTP 401)؛
  - بقاء السر في `App.config` على القيمة المؤقتة
- **تسجيل خروج نظيف.** الزر **Sign Out** وإغلاق النافذة كلاهما ينهي الجلسة على الخادم فوراً

تصحّح الحزمة أيضاً ساعة الحاسوب الخاطئة تلقائياً، وترفض أي رد يدّعي النجاح دون تشفير

## المتطلبات

- نظام Windows 10 أو أحدث
- برنامج Visual Studio مع حزمة العمل .NET desktop development
- إطار العمل .NET Framework 4.8.1

## الإعداد

ضع سر التطبيق المكوّن من 64 حرفاً في الملف `PWFAuthCSharp/App.config`:

```xml
<add key="PWFAuthAppSecret" value="YOUR_64_CHARACTER_APP_SECRET" />
```

اضبط السر قبل التوزيع ولا ترفعه إلى المستودع أبداً. عنوان الخادم ثابت على `https://pwfauth.com`، ولا يُؤخذ بأي تغيير له عبر متغيرات البيئة

## البناء والتشغيل

1. افتح `PWFAuthCSharp.slnx` في Visual Studio
2. استعِد حزم NuGet عندما يُطلب منك ذلك
3. اختر `Debug | Any CPU` واضغط `F5`

هل تحدّث نسخة أقدم من هذا المثال؟ استعِد حزم NuGet مرة واحدة كي يحل `PWFAuth` 1.7.0 محل الإصدار الأقدم في المجلد `packages`
